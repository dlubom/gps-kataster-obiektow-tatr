## Kontrakt i ograniczenia

- Całe warstwy: `Topografia___wektor_MIL1/MapServer/6` (jaskinie),
  `SIPTPN/Geologia_i_gleby/MapServer/3` (leje),
  `SIPTPN/Dziedzictwo_kulturowe/MapServer/13` (sztolnie/kopalnie).
- Jeden UTF-8 JSON z wcięciami, osobne warstwy. Wszystkie atrybuty
  bez interpretacji, geometria żądana w EPSG:4326 (x=lon, y=lat), pełne
  metadane JSON i XML warstw, URL-e zapytań i przedział pobrania UTC.
- Bez filtrowania geograficznego i deduplikacji między warstwami.
  Nowe pola są zachowywane automatycznie. Null i daty źródłowe bez zmian.
- Pełną listę OBJECTID i niezależny licznik sprawdzamy przed i po pobraniu.
  Rekordy pobieramy partiami jawnych ID do limitu serwera (maks. 500).
  Sprawdzamy kompletność każdej partii i `exceededTransferLimit`.
- Nie deklarujemy transakcyjnego obrazu serwera: zmiana wartości istniejącego
  rekordu podczas pobierania może pozostać niewykryta. Zapisujemy przedział czasu.
- Błędy HTTP/API (także HTTP 200), wadliwe odpowiedzi lub brak kompletu:
  kod 1, stderr, brak pliku wynikowego. Bez automatycznego zastępowania danych.
- `--output PATH`, `--timeout SECONDS` (domyślnie 30). Domyślny plik
  `data/sources/tpn/api/tpn-<UTC>.json`; istniejący plik nie jest nadpisywany.
  Zapis gotowego wyniku atomowo, po pobraniu wszystkich trzech warstw.
- Katalog `data/sources/tpn/api/` jest ignorowany przez Git; pierwszy zrzut
  pozostaje wyłącznie lokalnie. Katalog YAML i istniejące źródła bez zmian.
- Bez importu, porównań, skilla, harmonogramu, zmiany starych PR, merge i release.
