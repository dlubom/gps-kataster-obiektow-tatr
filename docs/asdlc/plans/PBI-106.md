# Odczyt wysokości NMT TPN — PBI-106

**Cel:** odczyt wysokości gruntu dla jednego punktu WGS84 przez publiczne
API TPN oraz lokalny skill uruchamiający ten odczyt. Zakres zatwierdzony
przez użytkownika 2026-10-21 po rozmowie projektowej.

**Spec:** [spec v2 §4.3, §6–7](../../../specyfikacja_gps_kataster_obiektow_tatr_v_2.md).
To pomocniczy odczyt, bez importu do modelu `Pomiar`.

**Architektura:** moduł `src/gps_kataster_obiektow_tatr/tpn_elevation.py`,
CLI `scripts/tpn_elevation.py` i skill `.agents/skills/tpn-elevation/SKILL.md`.
Python >=3.12, biblioteka standardowa, bez nowych zależności. Realizacja
w obecnej sesji na osobnej gałęzi od czystego aktualnego main.

## Kontrakt

- `--lat`, `--lon`: skończone liczby w stopniach dziesiętnych EPSG:4326.
- Domyślnie czytelny tekst; `--json` zachowuje wartość liczbową i oryginalny
  tekst wartości API. `--timeout` ogranicza pojedyncze żądanie HTTP.
- Jednopasmowy NMT `nmt_05m_mggp_2019`, siatka 0,5 m, EPSG:2178.
  `MapServer/identify`: `geometry=lon,lat`, `sr=4326`, `layers=all:0`,
  `tolerance=0`, mały jawny `mapExtent`, `imageDisplay=1000,1000,96`.
- Sprawdzamy powiązanie usługi z portalowym itemem i metadane źródła.
  Zmiana modelu/parametrów źródła wymaga ponownego przeglądu, nie otrzymuje
  automatycznie starej etykiety i rozdzielczości.
- Wynik: współrzędne, wysokość, model i rok w jego nazwie, źródła/żądanie,
  czas pobrania UTC, hashe metadanych i odpowiedzi; data pomiaru `unknown`,
  najnowszość `unconfirmed`, układ pionowy i dokładność pionowa `unknown`.
  WGS84 na wejściu nie jest deklaracją układu wysokości. Tekst nie używa
  „m n.p.m.” ani „nad elipsoidą”. Liczba cyfr nie jest dokładnością.
- NMT przedstawia grunt, niekoniecznie otwór w ścianie lub przewieszce.
- Brak danych, zmiana kontraktu, wadliwy JSON/XML, błąd ArcGIS również
  w HTTP 200 i błąd transportu: niezerowy exit, diagnostyka na stderr.
  Bez zastępowania wyniku zerem lub innym modelem.
- Bez zapisów katalogu, konfiguracji globalnej, nowych zależności,
  zmiany `best`, merge, tagu i wydania.

## Przegląd ryzyk

Testy obejmą odwrócone osie, NoData i puste wyniki, HTTP 200 z błędem
ArcGIS, niepoprawne/niejednoznaczne wartości i podmienione metadane źródła.
Źródło nie dokumentuje układu pionowego, RMSE ani interpolacji; wynik
zachowuje tę niewiedzę. Aktualizacja publikacji mapy nie datuje nalotu.
