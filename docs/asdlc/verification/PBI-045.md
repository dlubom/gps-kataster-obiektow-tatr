Zakres: jeden kandydat na trwałe ID w imporcie TPN; finalny YAML ma pierwszeństwo przed własną historyczną propozycją PIG. Sprzeczna tożsamość lub proweniencja nie może zostać arbitralnie scalona. Bez zmian finalnych danych, ID i numeracji pomiarów partii (PBI-046).

## Reprodukcja i poprawka

Regresje w `tests/test_tpn_staging.py` odtwarzają zaakceptowany obiekt PIG,
którego raport staging nadal istnieje. Na bazowym kodzie
`pytest -q tests/test_tpn_staging.py -k 'accepted_pig_object or conflicting_pig_provenance'`
dał **2 failed, 1 passed**: poprawny match z finalnego YAML stawał się
`unresolved`, a sprzeczne ID PIG w zachowanym stagingu nie były wykrywane.
Po poprawce te przypadki przechodzą; pełny plik ma 16 zielonych testów.

Importer scala kandydatów po `object_id` przed dopasowaniem. Ten sam trwały
obiekt z finalnego YAML i stagingu PIG jest uznany za tę samą tożsamość,
gdy pomiary niosą wspólny `PIG:ID`; finalny YAML daje aktualną jaskinię,
współrzędne i kolejny numer pomiaru. Brak potwierdzenia lub sprzeczna
proweniencja zatrzymują import z ID w komunikacie, zamiast wybierać
kandydata według kolejności. Dwa różne ID, mimo bliskiego punktu i tej
samej nazwy, nadal dają `TPN_NR_INWENT_AMBIGUOUS`. Zduplikowane, sprzeczne
wiersze PIG o tym samym ID są odrzucane. Puste rekordy `cave-only` i
propozycje bez odpowiadającego wiersza nie ukrywają następnego kandydata.
Dokumentacja kontraktu: specyfikacja §8.2 i `docs/operations.md`.

### Mutacje

Uruchomiono `mutmut run --max-children 2` dla czterech funkcji
`tpn_staging`: `build_tpn_staging`, `_load_pig_staging_candidates`,
`_pig_measurement_ids`, `_deduplicate_candidates`. Użyto istniejącego
obejścia `setproctitle` na macOS. Wynik: **367 killed / 149 survived**
z 516 mutantów, bez timeoutów i błędów narzędzia. Pełny lokalny wynik:
`build/verification/PBI-045-mutmut-all.txt`. Statystyka 6917 w UI dotyczy
wszystkich wygenerowanych mutantów repo, nie zakresu tego przebiegu.

Mutanty pomijające deduplikację, wybierające staging zamiast finalnego
rekordu, ukrywające dalszego kandydata albo akceptujące sprzeczną
proweniencję PIG zostały zabite. Ocalałe w `_deduplicate_candidates`
(18–20, 26) zmieniają tylko tekst błędu; w `_pig_measurement_ids` (3, 5)
równoważne domyślne `None`/brak argumentu są odrzucane przez następną
kontrolę typu. Pozostałe ocalałe (121 w `build_tpn_staging`, 22 w loaderze)
dotyczą starszych gałęzi przetwarzania wierszy, pól nazwy i globalid,
opcjonalnych wartości lub tekstu błędów; nie omijają nowej kontroli R08.
Pełna kampania innych funkcji pozostaje częścią PBI-054.
