## Implementacja

`scripts/tpn_elevation.py --lat LAT --lon LON [--json] [--timeout 20]`
wykonuje trzy publiczne odczyty HTTP, bez nowych zależności. Sprawdza
powiązanie usługi z itemem, jednoznaczną warstwę 0 (typ i nazwa), model,
siatkę, jedno pasmo i CRS z authority. Zmiana daje `SOURCE_CHANGED`.
Jawne `lon,lat`, `sr=4326`, `layers=all:0`, `tolerance=0`, mały extent.
Odczyt `Stretch.Pixel Value`, zachowanie tekstu API i hashy odpowiedzi/XML.

`retrieved_at` jest czasem pobrania UTC. Rok 2019 pochodzi z nazwy modelu;
data pomiaru, układ pionowy, dokładność i interpolacja są nieznane.
Lokalny `.agents/skills/tpn-elevation/SKILL.md` nie określa wyniku jako
n.p.m. lub nad elipsoidą. NMT opisuje grunt, nie gwarantowaną wysokość
otworu w ścianie/przewieszce. Błędy/NoData nie dają wysokości zastępczej.
