## Zakres

Nazwy jaskiń i otworów w etykietach GPX pozwalają rozpoznawać punkty
bez otwierania ich szczegółów.

- `wpt/name`: `Obiekt.name_local`, z zachowaniem nazwy konkretnego otworu;
  przy braku, `null`, pustej nazwie lub samych białych znakach: trwałe ID obiektu.
- `wpt/desc`: jawne `object <ID>` obok istniejącej nazwy, ID pomiaru,
  źródła, daty i uwag, aby nadal odnaleźć punkt w CSV/Excelu.
- Bez zmian danych, geometrii i wyboru best. Bez nowych zależności.
- Test regresji eksportu oraz przypadki polskich znaków, znaków XML
  i braku nazwy; pełna bramka, odczyt artefaktów i CI dokładnego SHA.
