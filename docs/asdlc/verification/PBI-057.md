## Poprawka i regresje

Selektory `_object_proposal_for_decision` i `_cave_proposal_for_decision`
wymagają istniejącego wiersza z raportu wskazanego źródła. Gdy wiersz
ma ID, jawne ID musi być takie samo. Bez ID jawna propozycja obiektu
musi mieć pomiar z `source` oraz `source_ref` zgodnymi z `pig_id`/`globalid`.
Dla jaskini PIG potwierdzeniem jest `PIG/catalog_id`; dla TPN powiązana
propozycja obiektu z właściwym pomiarem i zgodnym `cave_id`.
Niezgodność kończy tę decyzję jako `STAGING_OBJECT_PROPOSAL_MISSING`
lub `STAGING_CAVE_PROPOSAL_MISSING`, przed materializacją; błąd blokuje
zapis całej partii. Te same selektory służą rezerwacji ID przed alokacją
jawnych decyzji unresolved.

36 nowych przypadków w `tests/test_review_validation.py` używa dwóch
prawidłowych wierszy rzeczywistych importerów PIG/TPN. Obejmuje obie
akcje, przypisane/puste ID wiersza, brak wiersza, write/dry-run,
zgodny fallback, odwróconą kolejność propozycji i decyzji oraz odczyt
zapisanych YAML i ich walidację. Porównuje bajty katalogu i raporty;
nie tworzy brakującego celu przy błędzie/dry-run. Regresja legalnego
TPN `test_unresolved_allocation_reserves_explicit_tpn_proposal_id`
pozostaje bez zmian i przechodzi.

Na bazowym kodzie (przed zmianą aplikacji) `pytest -q
 tests/test_review_validation.py -k explicit_proposal`:
**20 failed, 16 passed, exit 1**. Wszystkie 20 wadliwych przypadków
były akceptowane. Czerwony wynik można odtworzyć przez `git archive`
bazowego SHA do osobnego katalogu, skopiowanie aktualnego pliku testów
i uruchomienie tego samego wyboru Pythonem projektu z `PYTHONPATH=src:tests`.
Żadne repozytoryjne YAML nie były celem reprodukcji.

Dwa wcześniejsze fixture'y wymagały doprecyzowania: test jawnego wyboru
propozycji ma teraz puste ID wiersza, a test rollbacku po zmianie ID
propozycji aktualizuje również ID wiersza. Zachowano wszystkie ich asercje,
w tym wybór wskazanego rekordu oraz wstrzyknięcie błędu ostatniego rename
i porównanie bajtów po rollbacku. Pierwsza pełna bramka wykryła ten drugi
stary fixture: **1 failed, 986 passed**, exit 1, bez dalszego builda.
