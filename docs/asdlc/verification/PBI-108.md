## Ograniczenia

Lista ID/count przed i po wykrywa utratę/zmianę zbioru, ale API nie daje
tu transakcyjnego obrazu kilku żądań. Zmiana wartości istniejącego rekordu
może pozostać niewykryta. Czas pobrania nie jest datą pomiaru.
Źródłowe statusy i niepewności nie są interpretowane. Zrzutów nie commitować;
bez merge, tagu i wydania. Brak kolejnego gotowego PBI w tym zakresie.
