## Zakres i decyzja

`build_db._insert_measurements` przekazuje wszystkie siedem pól liczbowych
pomiaru jako `float` lub `None` do kolumn SQLite `REAL`. Wymagane współrzędne
konwertuje wprost; pola opcjonalne używają istniejącego `_number_or_none`.
Walidator PBI-042 nadal odrzuca wartości niereprezentowalne jako skończony
`float` przed zapisem. YAML pozostaje źródłem prawdy; SQLite może zaokrąglić
duże liczby zgodnie z precyzją `REAL`. Nie dodano progów fizycznych.
Kontrakt zapisano w specyfikacji §12.2. `build_db.py` i jego testy dołączono
do konfiguracji mutmut; test tej konfiguracji jest z nią zgodny. Test CLI
builda pozostaje w zwykłym pytest, poza mutmut ze względu na subprocess.
