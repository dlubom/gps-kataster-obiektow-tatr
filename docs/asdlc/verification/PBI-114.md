## Odczyt artefaktów i niezmienność wejścia

Niezależny czytnik bez importu eksportera odczytał CSV, GeoJSON, wszystkie

Excel Best/Full, metadata i statystyki. Źródło odniesienia: zapisane YAML,
autorytatywny ID Best i cała historia 1928 pomiarów. **PASS**.

Pełny GPX porównany bajtowo z zapisem writerem bazowej rewizji przy tym samym
czasie: identyczny. Każdy waypoint części po odczycie XML identyczny z pełnym;
zbiory ID są rozłączne i ich suma równa pełnemu eksportowi. SHA-256 wszystkich
**2077** śledzonych plików data/config/schema sprzed i po zmianie zgodne.
Odczyt DBF uwzględnia udokumentowane 254 bajty UTF-8 i usuwanie prawego
wypełnienia pola; pełne opisy pozostają w GPX/CSV/GeoJSON/SQLite.

Minimalne odtworzenie kontroli GPX po zbudowaniu paczki:

```python
from pathlib import Path
from xml.etree import ElementTree as ET
import re

ns = '{http://www.topografix.com/GPX/1/1}'
root = Path('build/verification/PBI-114/exports')
def read(name):
    result = {}
    for p in ET.parse(root / name).findall(ns + 'wpt'):
        key = re.search(r'object ([A-Z]+-\d+)', p.findtext(ns + 'desc')).group(1)
        assert key not in result
        p.tail = None
        result[key] = ET.tostring(p)
    return result
full = read('best-measurements.gpx')
seen = {}
for name in ('chocholowska-lejowa-koscieliska.gpx', 'mietusia-sucha-woda.gpx', 'pozostale-pl-sk.gpx'):
    group = read(name)
    assert len(group) <= 500 and not seen.keys() & group.keys()
    assert all(full[key] == value for key, value in group.items())
    seen.update(group)
assert seen == full
```
