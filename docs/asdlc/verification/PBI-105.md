## Ograniczenia i kontynuacja

GitHub uruchamia `workflow_run` tylko gdy plik istnieje na default branch.
Pierwszy link jest komentarzem operatora po odbiorze rzeczywistego ZIP-a;
automatyczny zapis bota dla kolejnych PR wymaga przyjęcia tej zmiany.
Pełny test zapisu przez GITHUB_TOKEN na hosted workflow wymaga więc instalacji.
Zmiana samej bazy nie wyzwala buildu; przy konflikcie nie działa pull_request.
Nie rozstrzygamy jakości lokalizacji ani danych na podstawie udanego buildu.
Końcowy SHA, runy CI i artefakt wskazuje opis PR (bez samowskazującego commitu).
