## Dostarczone zachowanie

[Instrukcja i ścisły format](../tpn_sync_comparison.md) opisują CLI,
normalizację, strukturę raportu oraz odczytywanego stanu v1.

- `tpn_normalization.py`: exact Decimal JSON, NFC/LF/trim, null/zero,
  walidacja CSV i API, wersja/hash polityki, osobne revision/location hashes.
  CSV → WGS84 z polską kolejnością osi; tolerancja bootstrapu ≤0,1 m.
  API/API zachowuje każdą zmianę XY. Raw, wysokość CSV i czasy pozostają
  jawne; brak wysokości API to absent. Data edycji nie udaje obserwacji.
- `tpn_changes.py`: typed GUID → obiekt, legalne wiele GUID jednego obiektu,
  potwierdzanie historii przez source/source_ref i lokalizację, konflikty
  wieloznaczności. Raport zawiera pełne źródłowe before/after, katalog,
  preimage, wszystkie pola WER_LOK/UWAGI, odległość i lokalne różnice.
  Maszynowy JSON i czytelne tabele Markdown. Brak proponowanych akcji,
  kandydatów heurystycznych i zmiany best.
- `tpn_source_state.py`: tylko czytnik. CLI odczytuje rejestr ze wskazanego
  commitu origin/main, więc commit/PR nie akceptuje bazy. Fixture z własnym
  Git odtwarza kandydat na gałęzi → przyjęcie na main → no-op.
- Rozstrzygnięcia wiążą rewizję, politykę, cel i preimage/katalog. Defer
  zachowuje dawny dowód, reject nie obejmuje nowej rewizji/podstawy.
  Zapisane odciski rozpoznają powrót do historii mimo innego lokalnego ID.
  Osobne zdarzenia zniknięcia zachowują własne dowody; utrzymująca się
  nieobecność jest no-op, lokalna zmiana otwiera review, powrót cechy
  po przyjętej nieobecności wymaga review. Niepełny snapshot blokuje raport.
- CLI zapisuje tylko nowy katalog raportu, sprawdza bajty po zapisie,
  odmawia nadpisania i nie zapisuje katalogu ani source_state.

Wykonawcze doprecyzowania w granicach kontraktu: `result_catalog_hash`
dla zaakceptowanego wyniku, dowód CSV/API przy applied_locations oraz
jawny deskryptor poprzedniego źródła dla zdarzenia absence. Aktualny
rejestr przechowuje ostatnią decyzję per rewizja; starsze decyzje pozostają
w immutable source_reviews. Producent/review/apply tych plików to PBI-100.
