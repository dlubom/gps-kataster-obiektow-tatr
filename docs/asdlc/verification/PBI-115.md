# Usunięcie punktów reprezentujących systemy — PBI-115

Decyzja źródłowa z 2026-10-24.

## Decyzje źródłowe i zakres danych

- [PIG 10935](https://jaskiniepolski.pgi.gov.pl/Details/Information/10935)
  opisuje system Pawlikowskiego, a współrzędne główny otwór Mylnej;
  właściwy obiekt KSZ-0064 już istnieje. KSZ-0009 nie był dodatkowym otworem.
- [PIG 490](https://jaskiniepolski.pgi.gov.pl/Details/Information/490)
  podaje geometryczny środek systemu Wielkiej Śnieżnej. MLZ-0029 nie
  reprezentował fizycznego otworu. Oba opisy potwierdzono także w lokalnym
  źródłowym JSONL (wiersze 4036 i 41).
- Użytkownik jawnie polecił usunąć oba Obiekty i pojedyncze pomiary,
  bez dodatkowego archiwum i bez przenoszenia pomiaru do Mylnej. To korekta
  nieprawidłowej identyfikacji obiektu, nie ocena dokładności katalogu PIG.
- `C-0095` i `C-0295` zachowano bez własnych otworów, referencjami PIG,
  dotychczasowymi nazwami i nowym wyjaśnieniem w notes. Szerszy model
  systemów i historycznych części: [issue #34](https://github.com/dlubom/gps-kataster-obiektow-tatr/issues/34).
Ponowne użycie wycofanych ID pozostaje otwartym tematem
[issue #33](https://github.com/dlubom/gps-kataster-obiektow-tatr/issues/33).
Położenie Mylnej wymaga osobnego porównania z LiDAR:
[issue #36](https://github.com/dlubom/gps-kataster-obiektow-tatr/issues/36).
